# e2xgrader_restricted_notebook_extension

[![Github Actions Status](https://github.com/e2xgrader/e2xgrader-restricted-notebook-extension/workflows/Build/badge.svg)](https://github.com/e2xgrader/e2xgrader-restricted-notebook-extension/actions/workflows/build.yml)

A JupyterLab notebook-extension that restricts the user e.g. for use in exams or similar environments.

## Requirements

- JupyterLab >= 4.0.0

## Install

To install the extension, execute:

```bash
pip install e2xgrader_restricted_notebook_extension
```

## Uninstall

To remove the extension, execute:

```bash
pip uninstall e2xgrader_restricted_notebook_extension
```
